# 윤슬 상담실 — 기억하는 AI 심리상담

상담사 캐릭터 '윤슬'이 내담자의 이야기, 문장완성 응답, 반복되는 패턴을 기억하고
다음 회기에서 그 기억을 이어받아 상담하는 앱입니다.

## 실행

AI는 Google Gemini API(무료 등급)를 씁니다. 기본 모델은 `gemini-3.8-flash`입니다.

1. https://aistudio.google.com/apikey 에서 무료 API 키를 발급받습니다.
2. `start.bat`을 더블클릭합니다. 처음 실행하면 필요한 프로그램을 설치하고 `.env` 파일을 메모장으로 엽니다.
3. `GEMINI_API_KEY=` 뒤에 키를 붙여 넣고 저장합니다.
4. `start.bat`을 다시 실행하면 브라우저에서 http://localhost:8000 이 열립니다.

> **개인정보 주의**: Gemini **무료 등급**에서는 입력한 내용이 Google의 서비스 개선에 쓰일 수 있다고
> 공식 가격 안내 페이지에 적혀 있습니다. 실제 내담자에게 서비스하려면 유료 등급(결제 등록)으로 바꿔 이 사용을 막아야 합니다.
> 무료 사용량을 넘으면 `.env`의 `GEMINI_MODEL`을 `gemini-3.5-flash-lite`로 바꿔 볼 수 있습니다.

## 상담 흐름

- **입장**: 이름(별명)만 정하면 바로 시작합니다. 기록은 이 컴퓨터의 `data/clients/` 폴더에만 저장됩니다.
- **마음 점검 (상담 전)**: 원하는 점검을 골라 한 문항씩 답합니다(전체 약 20분).
  - 지금의 마음 상태: 우울(PHQ-9), 불안(GAD-7), 스트레스(PSS-10), 자아존중감(RSES)
  - 기질과 성격: TCI(Cloninger) 7차원 모델을 참고해 이 앱에서 새로 만든 35문항. 공식 TCI는 저작권이 있는 유료 검사라
    문항을 쓰지 않았고, 규준이 없어 점수는 상대적 경향으로만 보여 줍니다.
  - 문장완성검사: 24개 문장을 직접 이어 씁니다. 상담 중 대화에서 건네는 문장완성과 같은 기록으로 쌓입니다.
  - 점검을 마치면 윤슬이 모든 결과를 엮어 **종합 해석**(전체 이해, 기질·성격, 문장완성의 주제와 인용, 강점, 상담 초점)을 써 주고,
    첫 상담은 "해석을 읽어 보니 어떠셨나요?"에서 시작합니다. 내담자에게 보이지 않는 상담사 메모(사례개념화 가설)도 함께 저장됩니다.
  결과는 진단이 아니라 참고 자료로 보여 주고, 윤슬이 상담에서 탐색 재료로 씁니다.
  다시 점검하면 이전 결과와의 변화가 함께 기록됩니다. PHQ-9의 자해 생각 문항에 응답하면 위기 연락처를 바로 안내하고,
  윤슬이 상담 초반에 안전을 확인합니다. 문항은 원 척도를 한국어로 옮긴 것이라, 임상에서 쓰려면 타당화된 공식 한국어판으로 바꿔야 합니다.
- **초기 회기**: 윤슬이 대화 흐름 속에서 기본 정보(호소 문제, 생활, 수면, 관계, 가족, 이전 상담 경험, 안전, 목표)를 알아가고,
  알맞은 순간에 **문장완성 카드**("사람들은 나를 ___")를 건넵니다. 응답은 그냥 넘기지 않고 함께 더 탐색합니다.
- **회기 마무리**: "오늘 상담 마치기"를 누르면 회기 요약, 다음까지 가져갈 과제, 이어서 다룰 주제가 정리되고
  사례개념화(핵심신념 가설, 반복 패턴, 촉발 상황, 강점, 목표)가 갱신됩니다. 대화 중에도 6번마다 중간 갱신됩니다.
- **다음 회기**: 윤슬이 지난 기억을 바탕으로 먼저 말을 겁니다. 왼쪽 **'윤슬의 기억'** 패널에서 윤슬이 이해한 내용을 언제든 볼 수 있고, 모두 지울 수도 있습니다.

## 얕은 상담을 피하기 위한 설계

상담 원칙은 [prompts.py](prompts.py)의 `PERSONA`에 있습니다. 섣부른 조언·일반론 금지, 구체적인 장면으로 내려가기,
감정→생각→신념→패턴으로 층 내려가기, 지난 회기·문장완성과 연결해 가설 제시하기, 한 번에 한두 개의 질문,
작은 행동 실험 설계와 다음 회기 점검 등을 지시합니다. 이 문구를 고치면 상담 스타일이 바뀝니다.

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | FastAPI 서버, Gemini 스트리밍 호출, 회기 검토(기억 갱신) |
| `prompts.py` | 윤슬 페르소나·상담 원칙, 기본 정보 항목, 문장완성 문항, 기억 → 프롬프트 변환 |
| `tests.py` | 마음 점검 검사 문항(척도·기질성격), 채점, 상담사에게 넘길 요약 |
| `sct_items.py` | 문장완성검사 문항 |
| `store.py` | 내담자별 JSON 파일 저장 |
| `static/` | 화면 (HTML/CSS/JS), 상담사 캐릭터 일러스트 `counselor.svg` |


## 주의

윤슬은 AI이며 진단·처방을 하지 않고 전문 치료를 대신하지 않습니다. 위기 상황에서는
자살예방상담전화 109, 정신건강위기상담 1577-0199, 112/119로 연락하도록 안내합니다.
